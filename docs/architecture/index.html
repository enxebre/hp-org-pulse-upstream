02 / IDENTITY & ACCESS

Two ways in, shared permission checks.

People sign in through OpenShift OAuth. Automation uses scoped Org Pulse API tokens.

Open SVG ↗
Browser identity

Automation

Authorization
Required roles + token scopes

The proxy guard enforces X-Proxy-Secret when PROXY_AUTH_SECRET is configured, with exceptions for selected public endpoints and valid API tokens. Token scopes supplement the required user roles. Local development falls back to the first ADMIN_EMAILS entry. External API routing for automation depends on deployment configuration.

03 / FROM SOURCE TO SCREEN

Pull source data. Receive AI results.

Refresh handlers cache upstream data; external pipelines push computed assessments and snapshots. Views read the resulting datasets.

Open SVG ↗
Pull integrations
Jira · GitHub · GitLab
Push integrations
Assessments · test plans · decomposition
Display
GET APIs → composables → charts

The documented scheduler ticks every 15 minutes; most handlers have a 24-hour default cadence. CVE Triage and Backport Tracker can fetch on an initial cache miss. Heavy AI analysis belongs in external pipelines; the app still calculates dashboard metrics. Demo storage reads fixtures and ignores writes.
